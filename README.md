# Handwritten Digit Recognition

## Overview
This project implements a **Handwritten Digit Recognition System** using deep learning techniques. The model is trained on the **MNIST dataset** to classify digits from **0 to 9** with high accuracy.

---

## Features
- Classifies handwritten digits (0–9)
- Uses neural networks for accurate predictions
- Data preprocessing and normalization
- Model evaluation with accuracy metrics
- Simple and efficient implementation

---

## Tech Stack
- **Programming Language:** Python  
- **Libraries:** TensorFlow / Keras, NumPy, Pandas, Matplotlib  
- **Dataset:** MNIST  

---

## Dataset
The project uses the **MNIST dataset**, which contains:
- 60,000 training images  
- 10,000 testing images  
- Grayscale images of size 28x28 pixels
